Conceito Bootstrap

Bootstrap é um framework front-end utilizado para facilitar a criação de interfaces de sites e sistemas.

Ele oferece componentes prontos, como botões, formulários, tabelas, alertas e janelas modais, além de recursos para deixar as páginas responsivas.

Aplicação no nosso projeto: Poderíamos utilizar o Bootstrap para desenvolver os botões, organizar o formulário, estilizar a tabela e criar os modais de confirmação de maneira mais rápida e padronizada.

Nesta versão, os componentes foram desenvolvidos com HTML, CSS e JavaScript personalizados, seguindo os conceitos de interface apresentados pelo Bootstrap.
